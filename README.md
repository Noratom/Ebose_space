# Ebose_space

Ebose's Kitchen Kronikles — Full-Stack Recipe Platform & CMS Admin Portal

## Features
- **Interactive Recipe Catalog**: Search, filter by category & dietary tags, view step-by-step instructions.
- **Interactive Cooking Timer Bar**: Step-by-step cooking timer with audio completed chimes.
- **Multi-Platform Video Player**: Integrated player for YouTube, Instagram Reels, and TikTok recipe walkthroughs.
- **Midnight Espresso Dark Mode**: Header toggle switching between Warm Cream Daytime and Midnight Espresso stovetop cooking modes.
- **Reader Photo Uploads & Reviews**: Star ratings with photo uploads ("I Made This!").
- **Admin CMS Suite**: Complete dashboard for managing recipes, categories, tags, chef profile, team members, and site content.

## Deployment Setup

### Frontend (Vercel)
- **Root Directory**: `client`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

### Backend (Render)
- **Root Directory**: `server`
- **Build Command**: `npm install`
- **Start Command**: `node server.js`
